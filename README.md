# 🎓 KMITL Engineering Portfolio & AI Certificate Analyzer

> **Modern Engineering Portfolio สำหรับยื่นเข้าศึกษาต่อคณะวิศวกรรมศาสตร์ สถาบันเทคโนโลยีพระจอมเกล้าเจ้าคุณทหารลาดกระบัง (KMITL)**  
> **ผู้จัดทำ:** นายณัฐพงษ์ ดวงรัตน์ (แสตมป์) | นักเรียนชั้นมัธยมศึกษาปีที่ 6/6 โรงเรียนคลองขลุงราษฎร์รังสรรค์ (ห้องเรียนคุณภาพ SMT)

---

## 🚀 Concept & Design Highlights
- **Concept:** Modern Engineering Portfolio (Futuristic, AI, Technology, Engineering, Circuit patterns, Blueprint Grid)
- **Color Theme:** Crimson Red (#c01b2e / #800000) & Deep Dark Navy (#07090e) พร้อม Metallic Accents
- **Typography:** Kanit (ภาษาไทย) & Inter / JetBrains Mono (ภาษาอังกฤษและโค้ด)
- **Interactive Features:** 
  - Dynamic Circuit & Particle Canvas Background
  - Sticky Navigation Bar พร้อม Scroll Spy
  - Interactive Skill Gauges & Category Filters
  - **LNWMATH** AI-Powered Mathematics Learning Platform Showcase
  - **AI Certificate Analyzer** (OCR Text Extraction, Multi-Skill Tagging, 3-Tone University Portfolio Description Generator & Certificate Ranking)
  - Interactive Timeline for Research Conferences (The 3rd KPRU International Conference Presenter) & Hackathons

---

## 🛠️ Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript & JavaScript (ES6+)
- **Styling:** Tailwind CSS & Vanilla CSS Animations
- **Icons & UI Elements:** Lucide React
- **Celebration Effects:** Canvas Confetti

---

## ⚡ Quick Start (Local Development)

```bash
# 1. Clone repository
git clone https://github.com/FerKunG/PORTFOLIO.git

# 2. เข้าสู่โฟลเดอร์โปรเจกต์
cd PORTFOLIO

# 3. ติดตั้ง Dependencies
npm install

# 4. รัน Dev Server
npm run dev
```

เปิดเว็บเบราว์เซอร์ที่ [http://localhost:3000](http://localhost:3000)
